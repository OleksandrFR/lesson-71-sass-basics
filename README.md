# lesson-71-sass-basics — Картка персонажа

Урок 71: **SASS/SCSS: підключення та базовий синтаксис** (рівень 1).

## Що зроблено

- Sass встановлений локально: `npm install` → `devDependencies: sass`.
- Автокомпіляція працює: `npm run watch:css` (sass --watch scss:css).
- Усі стилі лежать у `scss/main.scss`; `css/main.css` тільки генерується компілятором.
- HTML підключає саме `main.css`.

## Картка

Персонаж — **Стів** (Minecraft), аватар зібраний SVG-квадратиками.

У картці є:

- зображення (SVG-аватар),
- ім'я,
- короткий опис,
- список із трьох здібностей,
- рейтинг ★★★★☆,
- дві кнопки (`Покликати в команду` / `Профіль`).

Використано: рамку, заокруглення, тінь, фоновий колір, `:hover` на кнопках, `cursor: pointer`.

У `main.scss` є однорядкові та багаторядкові коментарі.

## Як запускати

```bash
npm install
npm run watch:css
```

Відкрити `index.html` у браузері.
